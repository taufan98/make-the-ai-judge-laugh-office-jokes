One line about office life, under 200 characters. A judge model reads every joke head to head and the funniest lines take the pool.

## Run it

```sh
python3 main.py
```

The program writes one original one-line office joke (114 characters, 116 bytes) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` for local runs). Deterministic: every run writes the same bytes. Python 3.13, stdlib only, no network.
